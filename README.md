# Башня Бога — материал для игроков

Player-facing page for the D&D 5e campaign «Башня Бога».

The page is intentionally separate from the campaign Vault so GM-only notes are not published.

## Local preview

```bash
python3 -m http.server 8080
```

Open http://127.0.0.1:8080/

## Deployment

The intended deployment target is GitHub Pages.

## Content

The page presents three canonical ways for a character to enter the Tower:

- summoned by the Tower;
- illegal entry;
- entering for a personal goal or contract.

It also includes a local-only form that helps players prepare answers for the GM. Form data is stored in the browser's localStorage and is never sent to a server by this page.
